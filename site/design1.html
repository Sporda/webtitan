05 // README.md

# O mně

Jsem full-stack JavaScript vývojář se specializací na vývoj webových aplikací na míru, tvorbu webových stránek, interních systémů a komplexních API integrací.

Díky zkušenostem s technologiemi jako React, Node.js a TypeScript navrhuji moderní a škálovatelná řešení pro firmy i startupy. Poskytuji také vývoj e-shopů, digitální transformaci, správu serverů a další DevOps služby.

Jako freelance programátor nabízím flexibilitu a individuální přístup ke každému projektu – od návrhu až po úspěšné nasazení.
